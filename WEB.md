# Веб-версия (для iPhone)

Приложение можно открыть в браузере и поставить ярлык на экран «Домой» на iPhone. Откроется без адресной строки, как обычное приложение. Новых библиотек не добавлялось.

## Как выложить

1. В папке проекта: `npm install` (если ещё не делали), затем `npm run build:web`. Появится папка `dist`.
2. Выложите папку `dist` на любой хостинг статических сайтов. Проще всего Netlify: зайдите на app.netlify.com/drop, зарегистрируйтесь бесплатно и перетащите папку `dist` в окно. Получите адрес вида `https://что-то.netlify.app`.
3. Чтобы обновить сайт после изменений в коде, снова выполните `npm run build:web` и загрузите `dist` заново.

Перед загрузкой проверьте сборку: откройте `dist/index.html` в VS Code и найдите `apple-touch-icon` и `manifest.json`. Если их нет, ярлык на iPhone будет выглядеть как обычная закладка. Для этого в `app.json` должно быть `"web": { "output": "static" }` (так и стоит): в режиме `single` файл `src/app/+html.tsx` не используется.

Адрес сайта должен быть «в корне» (`https://что-то.netlify.app/`, а не `https://сайт/time-manager/`). Для GitHub Pages с подпапкой нужна отдельная настройка `experiments.baseUrl` в `app.json`.

## Как поставить на iPhone

1. Откройте адрес сайта в **Safari**.
2. Нажмите «Поделиться» (квадрат со стрелкой), затем «На экран “Домой”», затем «Добавить».
3. Дальше открывайте приложение с иконки на экране.

## Что важно знать

- Данные хранятся в памяти того устройства, где вы пользуетесь приложением. На iPhone они **не связаны** с Android-версией: задачи с Android здесь не появятся.
- Ярлык на экране «Домой» хранит данные отдельно от обычной вкладки Safari. Сначала добавьте ярлык, потом вводите задачи, иначе записи из вкладки Safari в ярлыке не появятся.
- Для запуска нужен интернет. Работу без сети не гарантируем.
- Удаление и подтверждения в веб-версии показываются обычными окнами браузера («ОК» / «Отмена»).

## Что менялось в коде

| Файл | Зачем |
|------|-------|
| `package.json` | команда `npm run build:web` |
| `src/app/+html.tsx` | оболочка страницы: иконка, название под иконкой, запуск без адресной строки |
| `src/components/app-tabs.web.tsx` | нижнее меню в браузере. Раньше там не было «Таймера», была ссылка на Docs и меню закрывало верх экранов |
| `src/web/alert-polyfill.js` | в браузере `Alert.alert` ничего не делает, поэтому удаление не срабатывало. Подключён только из веб-меню |
| `public/` | `manifest.json`, иконки для iPhone, правило для переходов по адресам |
